# 🚀 Counter Application

A simple and interactive Counter Application built using **React JS**.
This project demonstrates the use of **React Hooks (useState, useEffect)** and basic UI styling.

---

## 🌐 Live Demo

👉 https://anshukhg2003.github.io/CounterApplication/

---

## 📌 Features

* ➕ Increase Counter
* ➖ Decrease Counter
* 🔄 Reset Counter
* ⏰ Live Time Display
* 🎨 Attractive UI Design

---

## 🛠️ Technologies Used

* React JS
* JavaScript (ES6)
* HTML5
* CSS3
* Vite

## ⚙️ Installation

Clone the repository:

git clone https://github.com/anshukhg2003/CounterApplication.git

Go to project folder:

cd CounterApplication

Install dependencies:

npm install

Run the project:

npm run dev

---

## 🚀 Deployment

This project is deployed using **GitHub Pages**.

Build project:

npm run build

Deploy:

npm run deploy
